## Recommendations

- Treat every 🔴 as a release blocker; add an ownership filter or prove the caller enforces it.
- Reduce 🟠 by passing literal `where` at the query site, or by centralising private reads behind repository helpers that take a `userId` argument (so ownership is structural, not per-call).
- Wire `npm run security:audit -- --fail-on-high` into CI to block regressions.
- This is defence-in-depth alongside DB row-level security (see `docs/SECURITY-RLS.md`).
